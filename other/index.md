# Other
{: .no_toc }

식자재쿡 본사업(식자재쿡·브랜드쿡) 외의 **직영 인큐베이팅 브랜드**와 기타 참고 자료를 모아두는 섹션입니다.
{: .fs-6 .fw-300 }

식자재쿡은 영남권 유망 중소 외식 브랜드의 프랜차이즈 가맹사업화를 지원하며, 그 검증 사례로 직영 인큐베이팅 브랜드를 운영합니다. ([Company](/selly-strategy-table/company/) §5 성장 전략 참조)
